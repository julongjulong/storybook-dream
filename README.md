# 토끼 탐정과 열두 동화 사건 — v5

Windows용 가족 게임입니다. 인터넷 연결과 설치 없이 실행됩니다.

## 받아서 실행하기 (게임만 할 때)

1. 이 페이지 오른쪽의 **Releases**를 누릅니다. (또는 [최신 릴리즈](https://github.com/julongjulong/storybook-dream/releases/latest))
2. **Assets** 아래의 `storybook-dream-….exe`를 눌러 내려받습니다.
3. 받은 exe를 더블클릭하면 바로 게임이 켜집니다.

처음 실행할 때 Windows가 **"Windows의 PC 보호"** 창을 띄울 수 있습니다. 서명하지 않은 개인 제작 프로그램이라 그렇습니다. **추가 정보 → 실행**을 누르면 됩니다.

진행은 자동 저장됩니다. 다른 PC로 옮길 때는 게임 안의 **보호자 설정 → 백업 파일 저장**을 쓰세요.

> 초록색 **Code → Download ZIP**으로 받은 것은 게임 원본(소스)이라 더블클릭으로 실행되지 않습니다. 게임만 하려면 위의 Releases에서 exe를 받으세요.

## 원본에서 직접 실행하기 (개발할 때)

[Node.js](https://nodejs.org/) LTS를 설치한 뒤, 받은 폴더에서 PowerShell을 열고:

```powershell
npm install      # 처음 한 번
npm run app      # 게임 창으로 실행
npm run dist     # release 폴더에 exe 만들기
```

v5 개선 계획은 [docs/roadmap-v5.md](docs/roadmap-v5.md), AI 그림 프롬프트는 [docs/art-prompts-v5.md](docs/art-prompts-v5.md)에 있습니다.

## 키보드로 놀기

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 안전한 땅에서 걷기 |
| Space를 누른 채 방향키 | 밖으로 나가 선 긋기. 놓으면 정지하며 되짚기는 가능 |
| 1~4 | 획득한 해당 번호의 능력 즉시 사용 |
| Enter / Space | 그림책 다음 컷 |
| ← / Esc | 그림책 이전 컷 / 건너뛰기 |
| 방향키 + Enter | 지도에서 사건 선택·출발 |
| Esc | 놀이 일시정지, Enter 또는 Esc로 계속 |
| F | 전체 화면 전환 |
| M | 놀이에서 사건 지도로 |
| C | 홈·지도에서 하던 이야기 이어하기 |
| F3 | (개발 모드) FPS·판정 범위 오버레이 |

터치는 ‘선 긋기’ 버튼을 켠 다음 화살표를 사용하세요. 선물도 화면 버튼으로 쓸 수 있습니다. 조작 설명은 첫 튜토리얼에만 나오며, 터치 기기에서는 이후에도 이동 버튼이 표시됩니다.

## 열두 사건을 밝히기

플레이어는 토끼 탐정입니다. 거북이의 사라진 등껍질부터 나무 오리에 갇힌 잔치 손님까지, 동화 속 이상한 일을 조사합니다. 사건마다 소개 그림 세 컷, 땅을 밝혀 드러나는 발견 그림, 해결과 농담의 마무리 두 컷이 이어집니다. 공주 이야기는 없습니다.

어두운 곳의 **물음표 단서를 찾고, 목표 복원율도 채우면 완료**입니다. 선을 안전한 땅에 연결하면 작은 쪽 공간을 확보하고 갇힌 보스·졸병은 사라집니다. 보스를 먼저 가뒀더라도 남은 단서와 목표를 조사해야 합니다. 각 판은 하트 3개로 시작합니다. 공격에 맞아 현재 선이 취소되면 하트 1개가 줄며, 남은 하트가 있는 동안 확보한 땅은 유지합니다. 방패로 막으면 하트와 선이 유지됩니다. 하트가 0개면 판이 끝나고 Enter 또는 ‘다시 도전’으로 해당 사건을 처음부터 시작합니다. 그 판의 땅·걸음 별·아이템 사용 횟수는 초기화하고, 완료한 다른 사건과 획득한 선물은 유지합니다.

v4.1은 일반 탄막 속도를 약 25% 높이고, 둘째 사건부터 보스 이동은 약 10% 빠르게, 배회·회복 시간은 약 15% 짧게 조정했습니다. 예고 시간은 그대로입니다. 보스만 탄막을 사용합니다. 예고한 방향과 범위로 발사하며 공격 뒤 쉬는 시간이 땅을 얻을 기회입니다. 졸병은 돌아다니다가 붉게 준비한 뒤 잠시 빨라집니다. 첫 사건에는 탄막이 없고, 두 번째는 단발 입문, 이후 부채·고리·돌진·빛줄기가 조합됩니다. 확보한 땅을 파괴하거나 조작을 반대로 만들지는 않습니다.

기본 걸음은 천천히 시작하고 걸음 별 하나마다 뚜렷하게 빨라집니다. 별은 장면마다 세 개이며 피격해도 잃지 않습니다. 첫 사건 완료 후 다른 열한 사건을 고를 수 있고, 번호가 뒤일수록 도전이 커집니다.

## 네 가지 선물

| 번호 | 받는 때 | 선물 |
|---|---|---|
| 1 | 사건 2개 해결 | 거북이 보호막: 느려지는 대신 세 번 방어 |
| 2 | 사건 4개 해결 | 깃털 바람: 가까운 작은 적과 탄을 밀어 없애기 |
| 3 | 사건 7개 해결 | 숲길 등불: 공격을 지우고 적을 3초 멈추기 |
| 4 | 사건 10개 해결 | 꿈꾸는 시계: 적과 공격을 5초 멈추기 |

어떤 순서로 풀어도 해결한 사건 수로 받습니다. 재완료 시 중복 지급하지 않습니다. 획득한 선물은 모두 가져가고 장면마다 **도움 별 3개**를 공유합니다. 하나를 쓰면 별 한 개가 줄어듭니다. 각 선물은 최대 두 번, 시계는 한 번 사용할 수 있습니다.

## 시간과 꼬마 친구들

- **정오(2분)**: 꼬마 친구가 하나 더 나와요. **밤(4분)**: 하나 더 나오고 보스가 20% 빨라지며 덜 쉬어요. 게임 오버는 없고, 바뀌기 30초 전에 알려 줘요. 화면 위에 남은 시간이 보여요.
- **털뭉치**: 빨갛게 깜빡인 뒤, 토끼가 선을 긋고 있으면 빨간 점선 방향으로 곧장 돌진해요.
- **종이배**(4판부터): 토끼가 가는 방향 앞을 막으러 와요.
- **하트 조각**: 꼬마 친구를 가두면 조각 하나. 3개면 하트 하나가 생겨요. 하트가 가득하면 예비로 들고 있다가 다음에 맞을 때 대신 써요.

## 다시 하고 싶은 이유

- **판 별 3개**: 해결 · 하트를 하나도 잃지 않기 · 목표보다 15%p 넘게 밝히기(마지막에 크게 감싸기). 더 좋은 기록만 남습니다.
- **숨은 스티커**: 판마다 하나, 어둠 속에서 가끔 반짝입니다. 그 자리를 밝히면 사건 수첩에 붙습니다.
- **걸음 별**은 판마다 다른 곳에 있습니다.

## 저장과 다른 컴퓨터로 옮기기

진행, 남은 하트, 바꾼 가족 그림은 이 PC에 자동 저장됩니다(%APPDATA%\storybook-dream). 하트 0개인 판을 이어도 재도전 화면으로 돌아옵니다. 선을 긋던 중 끄면 마지막 안전 출발점에서 이어집니다.

다른 PC로 옮길 때는 **보호자 설정 → 백업 파일 저장**으로 storybook-save.json을 받고, 새 PC에서 **백업 불러오기**를 누릅니다. 가족 그림도 함께 옮겨집니다. v4의 "저장 자료 받기" JSON도 불러올 수 있습니다. v4의 이어하기 HTML은 브라우저로 열어 보호자 설정 → 저장 자료 받기로 JSON을 받은 뒤 불러오세요.

## 우리 가족 그림

보호자 설정에서 사건을 선택하고 PNG/JPG/WebP를 넣으면 복원할 배경이 바뀝니다. 그림은 PC 밖으로 보내지 않습니다. 사용자 그림은 게임 배경을 교체하고, 사건 소개와 마무리 그림은 유지합니다.

## 개발과 검증

Node.js가 있는 PC에서:

| 명령 | 하는 일 |
|---|---|
| `npm install` | 처음 한 번, 개발 도구 설치 |
| `npm run dev` | 브라우저 개발 서버 (http://localhost:4181). 코드 저장 시 바로 반영, F3 디버그 오버레이 |
| `npm run app` | 빌드 후 Windows 앱 창으로 실행 |
| `npm run dist` | release/ 폴더에 배포용 exe 생성 |
| `npm test` | 회귀 검사 |
| `npm run format` | 코드 정렬 |

assets/detective의 원본 PNG를 바꿨다면 scripts/prepare-art.ps1로 JPEG를 갱신하고 frames.json의 실제 패널 경계를 확인하세요.

코드 구조: `src/engine.js`(판 하나의 규칙) + `src/game/`(이동·적·보스·탄·저장 규칙), `src/render.js`(캔버스 그리기), `src/app.js`(화면·입력·저장), `electron/main.cjs`(Windows 창).

## Git으로 자료 관리

소스·디자인 원본·음악·기획 문서는 한 저장소에서 관리합니다. 경로, 처음 체크아웃한 뒤의 빌드 순서, 커밋 방법은 [저장소 관리 안내](docs/repository-guide.md)를 참고하세요. Git에서 받은 폴더는 먼저 npm run build를 실행해야 index.html이 생성됩니다.
