# 그림책 모험판 v2 — 최종 통합 기록

2026-09-14. 메인 기획자가 쉘든의 이야기, 에이미의 그림, 블루이의 엔진, 빙고의 음악, 힐러의 독립 검증을 통합했다. 최신 설계는 `game-design.md`, 독립 검증은 `QA-v2.md`가 기준이다. v1 보고서는 제작 이력이다.

## 결과

- 격자 판정과 화면 표시 좌표를 분리한 이동 보간. 짧은 방향키도 즉시 반응하고 키 반복이 속도를 높이지 않는다.
- Space를 누른 채 선 긋기, 놓으면 정지·뒤로 되짚기. 장면 이동·일시정지·포커스 상실 때 입력 해제.
- 번호 1~8로 획득한 모든 선물을 사용. 도움 별 3개 공유, 개별 횟수·대기시간 유지.
- 동화 번호별 목표 42~76%, 빨라진 적, 3탄부터 다섯 종류의 공격을 스테이지마다 다르게 배치. 2초 예고와 회복 구간, 복원 50%부터 강화.
- 그림과 말풍선이 연결된 37페이지. 원래 그림 8장과 신규 이야기 그림 11장, 총 19장.
- 음악 총 5곡. 보스 음악의 리듬 강도와 복원 진행을 연결하고 아침에는 별도 곡을 사용. 책장 넘김·패턴 효과음 추가.
- `index.html` 자체가 독립 게임이며 개발 페이지는 `dev.html`로 분리. 실행에 원본 그림·음악 파일이 필요하지 않다.

## 자동 검수

최종 전체 **92개 통과, 실패 0개**. 개발 엔진 43, 독립 엔진 33, 앱 모형 10, 콘텐츠 2, 내보내기 4개다. 모형 검수와 실제 브라우저 검수를 혼동하지 않는다.

빌드 검사로 모든 페이지의 그림 내장, 19장 JPEG, 원격 URL·외부 스크립트·외부 스타일 없음, 초기 저장이 비어 있음, 루트 index와 output 파일 동일함을 확인했다. 원본 PNG는 별도로 보존했다.

## 실제 브라우저 검수

Codex 브라우저에서 완성 HTML의 로컬 HTTP 미리보기를 사용했다.

1. Enter로 홈에서 지도로, 방향키로 3탄 선택, Enter로 소개 진입. Space와 Enter로 각각 다음 이야기·실제 게임 진입 확인.
2. Down만 누르면 시작 위치 (12,1)에 머묾. Space+Down을 짧게 누르면 (12,2)로 이동. Space를 놓은 뒤 Down은 (12,2)에 정지, Up으로 (12,1)에 되짚기 확인.
3. 숫자 1로 등껍질 사용 → 도움 별 3개에서 2개, 방패 3회, 남은 사용 1회 표시. 재개 시 사용량 유지 확인.
4. Esc 일시정지, M 지도 이동, C 이어하기 확인. 이전 v1 브라우저 진행의 완료 기록·등껍질을 새 버전에서 읽음.
5. 부채 패턴의 점선 예고와 방울, 쉬는 틈의 안내를 실제 화면에서 확인. 다른 패턴의 충돌·차단·순환은 엔진 자동 검사로 검증했다.
6. 새 동화 그림과 말풍선의 배치 확인. 노트북 화면에서 하단 버튼을 가리던 이전 높이 규칙을 제거하고 새 선물 가방까지 들어오도록 조정했다.
7. 1265×712, 390×844, 844×390 화면 크기에서 조작·선물 배치 확인. 휴대폰 가로 크기에서는 방향/그리기와 선물 가방을 오른쪽에 배치. 휴대폰 크기에서 가로 넘침 없음.
8. 검사 중 브라우저 오류·경고 로그 없음. 일부 시스템에서 표시되지 않던 깃털 기호를 잎 모양으로 교체했다.

## 남은 검증 범위

실제 Android/iPhone 기기, 실제 7세·성인의 체감 난이도와 장시간 플레이, 스피커 청감은 수행하지 않았다. 60fps 표시는 보간 설계의 목표이며 실제 기기에서 프레임률을 계측한 결과는 아니다.

검수 브라우저는 file:// 열기를 보안 정책으로 차단하므로 직접 파일 실행을 다시 시도하지 않았다. 단일 파일의 독립성은 정적 빌드 검사, 실행은 로컬 HTTP 미리보기로 구분해 검증했다. 다운로드 완료는 모형의 내용 검증과 구분하며, UI는 다운로드 폴더 확인을 안내한다.

음성 대사, 전용 보스 애니메이션 스프라이트, 모바일 설치 앱은 포함하지 않았다. 현재 버전의 감정 표현은 그림책·직접 작곡한 음악·짧은 감사 대사·시각 피드백을 통해 구성했다.
