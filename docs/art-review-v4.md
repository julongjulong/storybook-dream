# v4 메인 직접 그림 검수

2026-09-14. 에이미의 보고와 별도로 메인 담당자가 최종 원본을 직접 열어 확인했다. 대상은 12개 여섯 컷 시트(72장면)와 가족 그림 2장이다. 원본과 제작 프롬프트는 assets/detective 및 docs/art-notes-v4.md에 있다.

## 확인한 내용

| 사건 | 직접 확인 결과 |
|---|---|
| 토끼와 거북이 | 등껍질 없는 거북이 → 자국/수색 → 등껍질 발견 → 반환과 경주 → 토끼의 낮잠 패배와 윙크. 토끼 귀 두 개. 발견 클로즈업에서 귀 끝 일부가 프레임 밖인 구도는 허용. |
| 아기 오리 | 장화를 작은 오리 두 마리가 배처럼 사용 → 돌려받고 물놀이. 장화 한 켤레와 인물 수 확인. |
| 아기 돼지 | 비정상 문 위치와 설계도 발견 → 제자리 문. 발견 컷의 네 번째 돼지를 제거하고 세 마리로 수정. 설계도를 이미 펼친 순간으로 설명을 맞춰 종이모자 중복을 없앴다. |
| 빨간 모자 | 화분에서 열쇠 발견 → 할머니 문 열기 → 커다란 빵 나눔. |
| 잭과 콩나무 | 빈 종 자리 → 구름이 종을 모자로 사용 → 종 울리기와 거인의 쿠키. |
| 개미와 베짱이 | 잠긴 창고인데 수색 장면이 실내였던 오류를 발견. 중간 두 컷을 창고 밖 처마 아래로 수정한 결과를 재검수했다. 손잡이 발견 후에만 문이 열린다. |
| 사자와 생쥐 | 잎 아래 둥근 가위 → 몸과 떨어진 밧줄 자르기 → 다시 낮잠. 최종 글자 효과 제거판을 재확인했다. |
| 여우와 포도 | 새들의 발판이 된 낮은 사다리 → 지지하며 포도 따기 → 나눠 먹기. 낮은 A형 발판을 사다리로 허용했다. |
| 해와 바람 | 질문 컷에서 모자가 머리와 손에 중복된 오류를 제거. 발견 끈은 길고 좁게, 해결 컷은 실제 턱 아래를 지나도록 수정한 결과를 확인했다. |
| 금도끼 은도끼 | 무거운 금·은도끼 → 물가에서 쇠도끼 발견 → 반환 → 금도끼 문진 농담. |
| 피리 부는 사나이 | 빠진 마개와 수색 → 생쥐가 가진 마개 → 끼우기 → 즐거운 행진. |
| 트로이의 오리 | 첫·수색 컷에서 잃어버린 손잡이가 문에 이미 있던 오류를 발견. 최종판에서 빈 구멍만 남고, 발견·해결 컷에서 손잡이가 돌아오는 것을 확인했다. |
| 취침·아침 가족 그림 | 부모와 아이, 책 속 갈색 토끼/청록 목수건/두 귀, 아침 경주와 윙크 확인. |

## 실제 화면 표시

여섯 컷 원본을 파일로 잘라 재조립하지 않고 실측 좌표로 필요한 장면만 표시한다. 1254×1254 원본에서 구분선/여백을 제외한 frames.json을 사용하며 내장 JPEG 크기와 72개 영역을 빌드 검사로 대조했다.

PC 1280×800에서 소개 그림과 대사가 나란히 표시되고 Enter로 세 컷을 넘겨 게임에 진입하는 것을 확인했다. 지도는 사건의 첫 그림을 보여 주며, 게임은 네 번째 발견 그림을 어두운 막으로 가린다. 세로 390×844에서도 게임판과 네 아이템이 화면 안에 들어온다. 그림의 전체 비율을 유지해 발견 소품이 화면 가장자리에서 잘리지 않게 했다.

실제 휴대폰 터치, 어린이의 읽기·이해 정도와 장시간 플레이는 별도 사용자 테스트가 필요하다. 손가락 등 모든 픽셀의 무결함을 보장하는 검수는 아니다.
