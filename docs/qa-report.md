# 힐러 QA 보고서

검증일: 2026-09-14. 대상: `storybook-dream`의 로컬 동화 게임 소스. 이 보고서는 코드·자동 검증 결과이며 실제 어린이나 실제 휴대폰의 사용성 평가를 대신하지 않는다.

## 판정

검증한 핵심 규칙과 진행 연결은 통과했다. 작은 영역에 갇힌 적과 보스가 사라지고 그 영역이 내 땅이 되는 동작을 독립 시나리오에서 재현했다. 직선 및 꺾인 선 모두 확인했고, 큰 영역의 적은 보존된다.

`node --test tests/*.test.mjs` 최종 전체 **50개 통과, 실패 0개**. 그중 힐러가 독립 작성한 검증은 `qa.test.mjs` 20개, `app-qa.test.mjs` 6개다. 개발자의 엔진 검증 19개, 메인의 파일 내보내기 검증 4개와 선물 변경 시 진행 보존 검증 1개도 통과했다. 블루이의 짧은 터치·모달·화면 높이 수정과 메인의 선물 변경 시 체크포인트 보존 수정 후 재실행한 결과다.

## 앱 연결 검증 6개

실제 `app.js`와 `GameEngine`을 Node VM에서 실행했다. DOM·오디오·애니메이션 프레임은 작은 테스트 모형으로 대체했다. 따라서 화면 배치·실제 터치·실제 재생 검증으로 세지 않는다.

1. 새 게임에서 토끼와 거북이만 선택할 수 있고, 첫 완료 후 나머지 일곱 동화가 열린다. 첫 선물은 등껍질이다.
2. 여덟 장면에서 실제 엔진 포획 완료 이벤트를 차례로 발생시키면 완료 기록과 선물 여덟 개가 남고 아침 엔딩으로 연결된다. 엔딩을 건너뛰어 지도에 돌아와도 완료 기록이 유지된다.
3. 선을 긋다가 지도로 이동한 뒤 이어하기를 누르면 확보한 영역을 보존하고 안전한 출발점에서 재개한다.
4. 게임 파일에 들어 있는 진행과 브라우저 저장 중 최신 기록을 선택한다. 저장이 막힌 환경에서는 자동 저장 불가 문구가 표시된다.
5. 가져온 저장 자료의 현재 체크포인트에 미획득 능력이 들어 있어도 제거한다.
6. 애니메이션 프레임보다 빠른 짧은 터치도 한 칸 이동한다. 취소한 터치는 움직이지 않고, 이미 이동한 길게 누르기나 후속 클릭은 중복 한 칸을 만들지 않는다. 키보드로 버튼을 활성화하는 클릭도 한 칸 이동한다. 실제 손가락 입력을 재현한 것은 아니며 앱에 등록된 이벤트 함수를 실행한 검증이다.

## 발견하여 수정 확인한 항목

| 항목 | 상태 |
|---|---|
| 구두와 별을 함께 쓰면 너무 빨라지는 문제 | 최대 11.2칸/초로 제한. 회귀 검증 통과 |
| 정지 능력 중에도 보스 공격 준비 시간이 흐르는 문제 | 이동 감속 계수를 공격 시계에도 적용. 정지 중 발사 없음 확인 |
| 사과의 효과와 사용 횟수가 최종 기획과 다른 문제 | 보호 1회 + 별 1개, 장면당 1회로 수정. 회귀 검증 통과 |
| 내 땅 안에 적이 있는 손상된 체크포인트를 받아들이는 문제 | 복원 전에 거부하도록 수정. 회귀 검증 통과 |
| 손상 저장의 소수 방패·사용 횟수가 그대로 표시되는 문제 | 정수 횟수로 정규화. 개발자의 추가 회귀 검증 통과 |

위 항목은 메인/블루이의 수정과 병행하여 확인했으며, 힐러는 개발 파일을 중복 편집하지 않았다.

## 검증 범위와 남은 관찰

- 실제 브라우저의 화면, 키보드·터치 이벤트, 음소거·음량, 내보낸 HTML의 실제 파일 열기는 메인 통합 검수에서 별도로 기록한다.
- 이미지 여덟 장의 최종 연결 및 시각 품질, 오디오 청감은 이 자동 검증에 포함하지 않았다.
- 실제 7세 플레이어에게 첫 안내를 이해하는지, 기본 걸음이 편한지, 작은 영역 연결을 스스로 반복할 수 있는지 관찰한 뒤 수치를 다듬을 수 있다. 자동 검증 통과를 아동 사용성 검증으로 표현하지 않는다.
- 실제 iOS/Android의 파일 열기·다운로드·저장 정책은 기기별 확인이 필요하다. 이번 Node 검증으로 휴대폰 실기기 실행을 보장하지 않는다.
