# v2.1 속도·공격 흐름 QA

검증일: 2026-09-14. 담당: 힐러. 범위: 느려진 초기 플레이어 속도, 체감되는 별 성장, 빨라진 보스·작은 적, 예고와 공격·휴식의 일치, 저장 호환.

**최종 자동 검증 118개 통과, 실패 0개.** 최종 통합 `npm test` 실행 결과다. 기존 회귀 92개에 블루이 엔진 검증 14개, 힐러 독립 검증 11개, 메인 앱 검증 1개를 추가했다. 테스트를 삭제하거나 건너뛰지 않았다. 마지막 두 검증은 큰 프레임 간격에서도 돌진 최대 12칸 유지 및 정지 중 새 예고 방지, 손상된 돌진 저장 시간 제한이다.

## 판정 기준

- 기본 이동은 7칸/초, 별 1·2·3개는 8.8·10.6·12.4칸/초다. 별은 피격 후에도 유지되고 구두를 포함한 상한은 16칸/초다. 등껍질의 감속과 보호 횟수는 함께 유지한다.
- 적 이동 벡터 전체 속도가 스테이지 설정과 맞는다. 대각선 이동이 설정 속도보다 빨라지지 않는다.
- 예고 시작 때 방향을 고정한다. 공격 직전 재조준, 예고되지 않은 돌진 반사, 회복 중 남은 공격 탄이 없어야 한다.
- 작은 적의 추적은 눈에 보이는 예고를 거치며 보스 공격과 겹치지 않는다. 포획한 적은 재소환하지 않는다.
- 확보한 영역을 공격이 파괴하지 않는다. 확보한 한 칸 너비 벽에도 탄·빛줄기가 막힌다. 피격은 미완성 선만 지운다.
- v1·v2 저장을 가져와도 복원한 땅, 별, 선물, 사용 횟수, 도움 에너지와 보호 상태가 사라지지 않는다. 오래된 이동 속도만 새 기준으로 갱신한다.
- 멈춤·감속 능력은 이동뿐 아니라 예고·공격 시간에도 작용한다. 같은 프레임의 중복 접촉으로 보호막이 연속 소모되지 않는다.

## 기존 테스트의 기대값 변경 근거

사용자가 초기 이동 속도 감소와 적 속도 증가를 직접 요청했으므로, 기존 10칸/초·별당 1칸/초 증가 기대를 7칸/초·별당 1.8칸/초 증가로 변경했다. 별 세 개를 가진 뒤에도 구두의 효과를 느끼도록 메인 기획자가 총 상한을 14에서 16칸/초로 확정했다. 별 수 상한과 등껍질의 30% 감속은 보존한다.

이동 보간 테스트는 고정 0.1초에 한 칸 도착하는 것을 정답으로 삼지 않고 새 이동 속도에 따른 반 칸·한 칸 시간으로 검사한다. 부드러운 보간, 모서리의 직각 경로, 짧은 입력 1회만 처리, 반복키 중복 이동 방지라는 기존 검증 목적은 유지한다.

공격 검증은 스테이지별 예고·공격 지속 시간과 열린 고리 패턴에 맞춰 조정한다. 예고 후 공격, 고정된 조준 방향, 동시 탄 상한, 공격 종료 후 이동 속도 복구라는 기존 검증을 삭제하지 않는다. 수치 불일치와 기능 오류를 구분한다.

고정 2초 예고는 각 스테이지의 2.0~2.4초 설정으로 검사한다. 회복 시간도 고정 3초 대신 2.8~3.4초 설정을 사용한다. 마지막 장 강화 고리는 8발 전체 원에서 7발과 90도 출구로 바뀌었지만 전체 탄 상한 8개는 그대로 검사한다. 현재 저장 형식은 `engineVersion: 3`이며 v1·v2는 공격 상태만 안전하게 초기화하고 획득 영역·별·능력·에너지·버프를 보존한다.

## 독립 검증 결과

1. 세 별을 실제로 수집할 때 7 → 8.8 → 10.6 → 12.4로 증가하며 피격 후에도 유지된다.
2. 8개 스테이지를 각각 35초 실행해 안전한 땅의 플레이어·방패·영역이 보존되고 적이 확보한 땅 안으로 들어가지 않는 것을 확인했다.
3. v1과 v2 저장을 별도로 구성해 확보 영역과 수집 정보 보존, 낮은 옛 적 속도의 새 기준 정규화를 확인했다.
4. 별 3개 + 구두는 16칸/초, 여기에 등껍질을 쓰면 11.2칸/초다. 보호 세 번을 소모하면 구두 속도로 돌아온다.
5. 정지 아이템 중 적·예고·남은 시간이 멈추고 플레이어는 움직인다.
6. 한 칸 너비 확보 영역에 빠른 탄과 긴 빛줄기가 막힌다.
7. 각 스테이지의 모든 공격 순서를 실행해 표시 각도와 실제 공격 각도가 같고, 발사형 보스가 예고·발사·회복 동안 멈추는 것을 확인했다. 회복 시작에는 탄·빛줄기가 모두 사라진다.
8. 돌진이 확보 영역에 닿으면 반사하지 않고 멈추며, 산책 속도로 복구한다.
9. 추적형 작은 적은 멈춰서 1.5초 예고하고 고정한 방향으로 달린다. 보스 예고가 시작되면 추적을 취소하며 보스 공격 중 다시 추적하지 않는다.
10. 손상된 적 저장 자료의 예외를 재현하고 수정 후 회귀 테스트를 통과했다.

## 발견과 수정

| 발견 | 조치와 확인 |
|---|---|
| 적 목록에 `null`이 들어 있는 손상 저장을 읽으면 보스 수 검사에서 예외 발생 | 블루이가 null 검사 추가. 새 게임을 중단하지 않고 저장을 원자적으로 거부하는 독립 회귀 검증 통과 |
| 새 예고·속도·회복 시간 때문에 과거 고정 수치 기대와 불일치 | 위에 기록한 기획 근거에 따라 기대값만 조정. 기존 포획·보간·입력·저장·아이템 검증 목적 유지 |
| 돌진 예고 저장 시 폭이 달라질 수 있음 | 블루이가 자체 저장 왕복 검증에서 발견해 복원 폭을 수정. 신규 엔진 테스트 통과 |

검토한 자동 검증 범위에서 진행을 막는 미해결 오류는 발견하지 못했다. 이는 모든 플레이 경로의 무결점 보장을 의미하지 않는다.

## 검증 범위의 한계

메인 통합 확인: 로컬 HTTP로 제공한 독립 HTML을 브라우저에서 실행했다. 키보드로 첫 장을 시작하고 첫 걸음 별을 직접 수집해 화면이 ☆☆☆에서 ★☆☆로, DOM에 표시한 실제 속도가 8.8로 바뀌는 것을 확인했다. 이후 피격·일시정지에도 별 단계가 유지됐다. 지도에서 8탄으로 이동해 열린 고리 예고와 민트색 출구, HUD 배치를 확인했다. 공격 안내의 중복 토스트가 장면 아래를 가리는 점은 안내를 캔버스 아래 힌트로 옮겨 수정했다. 최종 빌드의 외부 의존성·기본 저장 비어 있음·루트/출력 HTML 일치도 배포 검사로 확인한다.

엔진 자동 검증은 실제 게임 로직을 실행한다. 실제 화면 표시·키보드·모바일 배치와 완성 파일의 브라우저 실행은 메인 통합 검수 담당이다. 실제 7세 아동과 성인의 재미·체감 난이도, 실제 휴대폰 성능은 자동 테스트만으로 확정하지 않는다. 특히 새 속도는 가족 플레이로 첫 별 획득 시간, 피격 빈도, 예고 후 회피 성공을 관찰해야 한다.
