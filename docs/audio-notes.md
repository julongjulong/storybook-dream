# 빙고의 오디오 제작 보고

이 게임을 위해 직접 작곡한 다섯 곡을 Web Audio로 합성합니다. 외부 음원, 샘플, 다운로드, 라이선스 표기 의무가 있는 음악은 사용하지 않습니다. 기존 상용 게임의 멜로디를 옮기거나 변주하지 않았습니다. 게임 파일 안에 악보와 악기 코드가 함께 들어가므로 인터넷 없이 재생됩니다.

| 장면 | 곡 | 박자·길이 | 성격 |
|---|---|---|---|
| 오프닝·동화 선택 | 책갈피 속 달빛 | 4/4, 72 BPM, 8마디, 약 26.7초 반복 | C장조 중심의 느린 자장가. E–G–A의 올라갔다 내려오는 첫 동기가 꿈에 들어가는 느낌을 줍니다. |
| 인게임 | 통통, 이야기 한 조각 | 4/4, 96 BPM, 8마디, 20초 반복 | 짧게 감쇠하는 둥근 플럭 음색. 2·4박의 가벼운 화음, 쉬는 박을 넣어 조작을 재촉하지 않습니다. |
| 스테이지 성공 | 우리 손으로 되찾은 아침 | 4/4, 80 BPM, 8마디, 24초 반복 | C–E–G–C의 상승 동기로 성취감을 표현합니다. 마지막 C장조 착지 후 부드럽게 처음으로 이어집니다. |
| 보스와의 모험 | 꼬인 책갈피의 작은 모험 | 4/4, 100 BPM, 8마디, 19.2초 반복 | A단조의 호기심에서 C장조의 자신감으로 움직이는 밝은 모험곡. 짧은 엇박 화음과 부드러운 저음으로 보스 장면을 구분합니다. |
| 책이 돌아온 아침 | 햇살이 책장을 넘기면 | 4/4, 64 BPM, 8마디, 30초 반복 | 오프닝의 E–G 동기를 넓은 C음으로 풀어내고 마지막 두 마디는 C장조로 머무릅니다. 한 박 쉬며 아침의 여운을 남깁니다. |

다섯 곡은 C장조와 A단조, F장조, G장조 화음을 공유하여 한 세계의 음악처럼 들립니다. 자장가에는 길게 유지하는 저음과 화음을, 플레이에는 짧은 멜로디와 분리된 화음을 썼습니다. 악기는 사인파 기반의 둥근 소리이며, 거친 파형·날카로운 타악기·깜짝 소리는 없습니다. 기본 마스터 볼륨은 45%이며 음표별 진폭도 별도로 낮췄습니다. 보스곡의 기본 음표 진폭은 기존 곡의 90%, 아침곡은 78%입니다. 가장 높은 음은 E5입니다. 실제 체감 음량은 기기 볼륨에 따라 달라집니다.

## 효과음

- `capture`: 짧은 두 음으로 땅을 되찾는 기쁨을 표시합니다.
- `pickup`: 세 음이 위로 올라가며 아이템 획득을 알려줍니다.
- `hit`: 낮고 부드러운 두 음으로 보호 효과 또는 충돌을 알립니다. 실패를 꾸짖는 소리가 아닙니다.
- `ability`: 네 음으로 능력 사용을 표시합니다.
- `win`: 여섯 음으로 완료를 축하합니다.
- `warning`: 같은 중음 두 번으로 공격 예고를 알려줍니다. 0.39초의 짧은 알림이며 길게 울리는 경보가 아닙니다.
- `dash`: 빠르게 올라가는 세 음으로 돌진 동작을 구분합니다.
- `beam`: 네 음으로 빛 공격을 표현합니다. 레이저 잡음 대신 부드러운 음정을 썼습니다.
- `page`: 짧게 내려오는 두 음으로 페이지 넘김을 표현합니다.

같은 효과음은 0.25초 안에 중복 재생하지 않으며, `warning`은 0.7초 간격으로 제한합니다. 새 네 효과음의 음량은 기존 효과음의 72%입니다. 동시에 살아 있는 음표 수도 제한했습니다.

## 개발 연동

`import { AudioDirector } from './audio.js'`로 클래스를 가져옵니다. 인스턴스는 하나만 만드세요. 사용자 클릭 또는 Space/Enter 키 입력 처리 안에서 `await audio.unlock()`을 호출한 뒤 `audio.play(scene)`을 사용합니다. `scene`은 `dream`, `play`, `celebrate`, `boss`, `morning` 중 하나입니다. `play()`를 먼저 호출해도 장면을 기억하고 `unlock()` 후 재생합니다.

`setMuted(boolean)`, `setVolume(0..1)`, `setIntensity(0..1)`, `effect(name)`, `pause()`, `resume()`, `stop()`, `destroy()`를 제공합니다. 생성자·음소거 설정·장면 선택은 AudioContext를 만들지 않습니다. 지원하지 않는 브라우저에서는 무음으로 진행하며 `unlock()`이 `false`를 반환합니다. 저장 데이터에는 음소거·볼륨 값만 기록하고 클래스 인스턴스는 저장하지 않습니다.

보스 단계가 바뀔 때 `setIntensity(0)`, `setIntensity(0.5)`, `setIntensity(1)`처럼 연결합니다. 강도는 보스곡의 작은 저음 리듬층만 조절하며, 이미 재생 중인 음·템포·마스터 볼륨은 바꾸지 않습니다. 타이머를 만들거나 음악을 다시 시작하지 않으므로 매 프레임 호출해도 안전합니다. 숫자는 0~1로 제한하며 NaN/Infinity는 무시합니다. 새 스테이지를 시작할 때 0으로 재설정하세요. `warning`은 예고 시작 순간에, `dash`와 `beam`은 실제 공격 시작 순간에, `page`는 페이지 전환 순간에 한 번씩 호출하는 방식이 적절합니다.

장면 전환 시 이전 예약음과 타이머를 지웁니다. 탭이 숨겨지면 일시정지하며, 돌아오면 수동 일시정지 상태가 아닐 때 곡 처음부터 다시 재생합니다. 사용자가 음소거해도 게임 동작은 달라지지 않아야 합니다.

## 제작 결과와 자동 확인

게임은 WAV 파일 없이 audio.js의 악보를 실시간으로 연주합니다. (v4 때 만든 미리듣기 WAV는 v5 정리 때 저장소에서 뺐습니다.)

Node의 AudioContext 대역을 사용해 다섯 악보의 길이, 오디오 미지원 환경, 사용자 동작 전 Context 미생성, 단일 Context 유지, 100회 장면 전환 후 타이머 중복 없음, 음소거·볼륨, 새 효과음 네 종류와 연타 제한, 강도 제한·잘못된 수치 무시·타이머 유지, 일시정지·재개·종료·해제를 확인했습니다. 이는 상태 검증이며 실제 기기 청취를 대신하지 않습니다.

## 청취 검수 권장 사항

노트북 스피커와 휴대폰 스피커의 낮은 볼륨으로 다섯 곡을 각각 두 번 반복해서 들어보세요. 보스 강도를 0→0.5→1로 바꿀 때 템포가 흔들리거나 갑자기 커지지 않는지, 장면 전환·연속 아이템 획득·음소거 전환·탭 복귀 때 갑작스러운 소리나 음악 중복이 없는지 확인해야 합니다. 첫 실행은 무음이어야 하며 시작 버튼 또는 Space/Enter를 누른 뒤 음악이 시작되어야 합니다. 기능 테스트와 별개로 아동이 직접 편안한 음량을 골라 짧게 플레이한 후 반복 음악이 피곤하지 않은지 확인하는 것이 최종 청취 검수입니다.
