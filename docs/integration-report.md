## 수정하고 확인한 규칙

작은 영역에 갇힌 적과 보스가 모두 사라집니다. 큰 영역은 남으며, 모든 적을 되돌렸다면 점유율이 낮아도 완성합니다. 실수는 현재 선만 지우고 이미 확보한 땅을 유지합니다.

기본 속도는 초당 8칸, 걸음 별마다 10% 증가하여 별 세 개일 때 10.4칸입니다. 구두 능력까지 합쳐도 11.2칸을 넘지 않습니다. 등껍질은 속도를 70%로 낮추며 세 번 보호합니다. 사과는 장면당 한 번, 보호 한 번과 걸음 별 한 개를 줍니다. 다른 능력은 두 번 사용할 수 있습니다.

튜토리얼은 목표 30%, 탄환 없음. 다른 동화의 목표는 처음 진입 당시 완성 수에 따라 약 46~62%입니다. 난이도 1까지 탄환이 없고, 이후에도 2초 예고·느린 방울·최대 두 발로 제한합니다. 제한 시간과 목숨 소진 게임 오버는 없습니다.

저장은 미완성 선 대신 안전 출발점을 기록합니다. 선물 가방에서 다음 능력을 바꾸어도 하던 장면의 저장을 지우지 않도록 추가 수정했습니다. 이어하기는 그 장면에 가져갔던 능력을 유지합니다.

## 확인하지 못한 범위

검수 브라우저의 URL 보안 정책이 `file://` 열기를 차단했으므로 파일 더블클릭 실행은 직접 검증하지 못했습니다. 차단을 우회하지 않았습니다. 단일 HTML은 로컬 HTTP 미리보기에서 실행했고 파일 독립성은 빌드 검사로 확인했습니다.

게임 파일 내보내기의 내용·이미지 포함·스크립트 보존·오류 처리는 모형 테스트를 통과했습니다. 실제 브라우저에서 저장 요청은 실행됐지만 다운로드 완료 이벤트와 생성 파일은 확인되지 않아 종단 간 다운로드 성공으로 기록하지 않았습니다. UI는 저장 완료를 단정하지 않고 다운로드 폴더 확인을 안내합니다.

실제 Android/iPhone, 실제 어린이의 난이도 적합성, 스피커·이어폰 청감은 확인하지 않았습니다. 아동의 대사 읽기는 보호자가 함께 도와줄 수 있으며 음성 내레이션은 포함하지 않았습니다. 모바일 앱 설치 패키지와 자동 기기간 동기화는 이번 결과물에 포함하지 않습니다.
