# 메인 담당자 그림 검수 — v3

2026-09-14. 에이미의 보고만으로 통과시키지 않고, 메인 담당자가 실제 PNG를 열어 확인했다. 35개 그림 키에 대응하는 34종의 그림을 검수했다. 백설공주 첫 장면은 정상 복원 그림을 재사용한다. 제작 프롬프트와 출처는 art-notes-v3.md에 있다.

## 직접 찾아 수정한 문제

1. 기존 race-twist에서 귀가 세 개임을 확인했다. 새 자전거 그림에서는 귀 두 개와 두 팔·두 다리, 자전거별 바퀴 두 개를 확인했다.
2. 첫 자전거 수정본은 타고 달리기보다 자전거를 붙들고 서 있는 모습이었다. 다시 그리도록 지시하고, 최종본의 안장·페달·발 위치와 회전 표현을 확인했다.
3. 아침 책 속 토끼에도 세 번째 귀처럼 보이는 부분을 발견했다. 양팔을 몸 앞으로 옮긴 최종본을 다시 열어 귀 두 개를 확인했다. 방 벽의 토끼 그림도 함께 확인했다.
4. 모바일 게임 아이템 이름이 키 번호와 겹쳤다. 아이콘 아래에 이름과 상태를 놓는 세로 배치로 바꾼 뒤 390×844에서 다시 확인했다.
5. 대사가 그림 위에 겹쳐 자전거 바퀴·발을 가리지 않도록 그림 옆 또는 아래에 배치했다. 최종 HTML의 토끼 1·2·3장면을 실제 Enter·Space로 넘겨 확인했다.

## 채택한 표현상의 차이

- 신데렐라 반전·해결 그림은 마차와 소품 중심으로 신데렐라의 대사는 화면 밖 목소리다. 무도회 준비 첫 컷에는 신데렐라가 등장한다.
- 백설공주 첫 컷은 인물 대신 집·모자·식탁·사과를 보여 준다. 글도 집과 간식 준비를 소개하도록 맞췄다.
- 구두 가게 안의 양말, 젤리집 옆에서 쉬는 늑대 등 기존 배경 소품은 남겼다. 한 가지 핵심 반전을 이해하는 데 지장이 없어 채택했다.
- 그림의 빵가루 고리와 방울은 서사 표현이다. 실제 공격 판정의 각도·개수·출구는 엔진의 예고와 렌더러가 담당한다.

## 실제 표시 확인

- 1280×720에서 그림과 대사가 나란히 보이고 토끼의 귀, 자전거 두 바퀴와 발이 가려지지 않는다.
- 390×844에서 그림·대사가 세로로 이어지고 첫 동화 3번째 이미지 로드, 다음/이전/건너뛰기 버튼을 확인했다. 가로 넘침 없음.
- 게임 보스는 플랫폼의 이모지 누락을 피하도록 캔버스 도형으로 그린다. 실제 바퀴와 거울 보스, 후반 네 갈래 빛줄기 예고를 확인했다.
- 아동 플레이를 통한 웃음·이해도 평가는 아직 하지 않았다. 이 기록은 제작물·화면의 직접 검수 결과다.
