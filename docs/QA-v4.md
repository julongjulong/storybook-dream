## 발견하고 수정한 화면 경계 차이

일반 탄의 예고가 직사각형에서 끊겨 원형 접촉 반경만큼의 끝부분이 표시되지 않았다. 실제 재현에서 오른쪽 조준탄의 중심 이동 끝은 x=66.16인데, x=66.5의 선 중심이 반경 0.65 안에 있어 충돌했다. 경고의 평평한 끝만 보면 표시 밖에서 맞은 것처럼 보일 수 있었다.

메인 담당자가 `dangerRay`에 일반 탄/돌진의 양끝 타원 캡을 추가했다. 화면이 늘어나도 월드 좌표의 반경을 각각 x/y 축척으로 변환한다. 독립 검증은 실제 `paintGame` 호출에서 일반 탄과 돌진에만 캡이 있고 빛줄기는 없음을 확인했으며, 위 x=66.5의 충돌 위치가 수정된 캡 내부임을 재검증했다.

## 이야기와 그림 연결 확인

토끼가 전 사건의 조사 주체이며, 이상 증상→자국/질문→수색→실제 단서 발견→반환/사용→사건 특유 농담으로 이어진다. 첫 사건은 등껍질 반환 후 경주, 토끼의 낮잠 패배와 플레이어를 향한 윙크를 유지한다. 오프닝의 꿈 진입 대사는 실제 표시할 조사 장면과 맞도록 “눈을 떠 보니 토끼 탐정 곁”으로 정리했다.

코드 검증은 artId 역할을 확인한 것이다. 12개 여섯 컷 시트에서 귀·손발·인물 수·소품 정체·정답의 사전 노출을 실제로 확인하는 작업은 메인/에이미의 시각 검수 기록을 따른다. 미완성 그림을 완성된 것으로 간주하지 않는다.

## 확인 범위의 한계

이번 독립 QA는 자동화된 엔진 상태와 캔버스 호출 검증이다. 실제 디스플레이의 성능, 아동·성인 플레이 난이도, 휴대폰 실기기 터치, 음향 청취, 다운로드 파일의 실행과 새 그림의 최종 납품은 별도 통합 검수 항목이다. 전체 완료를 보고할 때 이 결과만으로 해당 항목까지 통과했다고 주장하지 않는다.
