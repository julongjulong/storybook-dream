## 확인 결과

- **하트:** 새 도전은 3개. 보호받지 못한 실제 접촉마다 3→2→1→0으로 감소하고 실패 이벤트는 한 번만 발생한다. 밝힌 땅과 속도 별은 피격으로 사라지지 않는다.
- **보호:** 안전한 상태, 피격 후 무적 시간에는 하트를 차감하지 않는다. 거북이 보호막은 세 번을 모두 막은 뒤 다음 피격부터 하트가 줄어든다. 같은 무적 시간의 연속 접촉은 중복 차감하지 않는다.
- **실패 후 정지:** 마지막 하트를 잃으면 이동·아이템·경과 시간·추가 승리가 막힌다. 마지막 탄에 맞은 프레임에서도 다른 탄은 더 이동하지 않는다. 남은 공격과 예약탄은 정지 화면의 상태로 보존되며 이후 발사되지 않는다.
- **저장:** 하트 1개 상태와 실패 상태를 세 번 반복해서 불러와도 하트와 도움 별이 되살아나지 않는다. 하트 0인데 실패 플래그를 지웠거나, 실패 플래그가 있는데 하트를 3으로 바꾼 불일치 저장도 실패 상태로 정리한다. 이전 엔진 v1~v5 저장은 하트 3개로 시작하되 기존 도움 별 소비와 속도 별을 보존한다.
- **재도전:** 새 엔진으로 다시 시작하면 하트 3개·초기 속도·미복원 보드가 된다. 기존 실패 저장 객체를 변경하지 않는다. 실제 Enter 재도전과 실패 창의 버튼/저장 동작은 메인 앱 검수 범위다.
- **속도와 주기:** 첫 튜토리얼 수치는 유지된다. 2~12사건 보스 이동은 기존 대비 10% 증가, 공격 사이 이동 시간과 공격 후 휴식은 15% 감소한 값과 소수 둘째 자리 반올림 범위에서 일치한다. 탄속은 부채 11.8, 조준 14.2, 고리 10.5이며 최대 14발을 유지한다.
- **빠른 탄 판정:** 0.1초 한 프레임의 시작·끝 위치가 모두 선의 판정 밖이어도 이동 경로가 선을 통과하면 피격으로 판정한다. 탄속 증가로 선을 건너뛰는 현상이 없는지 확인했다.
- **예고:** 12사건의 실제 탄 방향·최대 이동 거리·빛줄기 팔이 현재 속도와 예고에 일치한다. 일반 탄·돌진의 경고 양끝 반경, 늘어난 화면의 폭 변환도 유지된다. 연사 간격은 0.1초와 1/60초 프레임에서 확인했다.
- **이전 기능:** 단서 발견 필수 완료, 적 없는 진행 복원, 삭제된 아이템의 에너지 보존, 실제 앱 저장 정리 함수의 완료 조합 4,096개 검증도 통과했다.

## 검증 과정의 조정

보스 휴식 2.7초의 15% 감소값 2.295를 2.29와 2.30 중 어느 쪽으로 반올림하는지는 부동소수점 표현에 따라 달랐다. 실질적인 수치 오류로 분류하지 않고 원래 곱셈 값에서 ±0.005초 범위인지 검증했다. 고리 탄 수 테스트는 탄이 화면 경계에 먼저 사라지는 경우와 발사 누락을 혼동하지 않도록 중앙에서 발사했다. 이전에 하드코딩한 탄속은 현재 패턴 규격을 참조하고, 확정 속도 자체는 별도 독립 검증으로 고정했다.

## 한계

이 결과는 자동 엔진·저장·캔버스 호출 검증이다. 실제 아이에게 적절한 난이도, 휴대폰 실기기 조작, 하트 HUD와 실패 모달, 다운로드 파일 실행, 음향 및 아트 완성도는 이 결과만으로 확인되었다고 할 수 없다. 해당 항목은 메인 담당자의 실제 통합 검수 결과를 따른다.
