# v2 힐러 QA

검증일: 2026-09-14. 범위: 새 Space 그리기 조작, 보간 이동, 고정 난이도, 보스 패턴, 전체 선물 사용, 그림 동화 및 키보드 흐름.

최종 자동 검증: **92개 통과, 실패 0개**. `node --test --test-reporter=spec tests/*.test.mjs`로 메인의 앱 회귀 수정과 블루이의 즉시 키보드 입력 수정 이후 다시 확인했다. 힐러 독립 검증 45개(엔진 33, 앱 모형 10, 콘텐츠 2), 개발자 엔진 검증 43개, 파일 내보내기 검증 4개로 구성된다. 검토한 범위에서 기능상 진행을 막는 미해결 항목은 없다.

## 검증 방식

- **엔진 자동 검증:** `tests/qa.test.mjs`의 독립 33개 시나리오. 실제 `GameEngine`을 실행해 위치·영역·공격·능력·저장 결과를 확인한다.
- **앱 모형 검증:** `tests/app-qa.test.mjs`의 10개 시나리오. 실제 `app.js`와 엔진을 Node VM에서 실행하며 DOM·오디오·애니메이션 프레임을 모형으로 대체한다. 등록된 키보드와 포인터 이벤트 함수를 직접 실행한다.
- **콘텐츠 자동 검증:** `tests/story-qa.test.mjs`의 2개 시나리오. 오프닝 3컷, 동화별 소개·복원 2컷씩, 엔딩 2컷과 그림 ID·짧은 대사를 확인한다.
- **실제 브라우저:** 메인 통합 검수 담당. 이 보고서의 모형 테스트가 실제 브라우저 테스트를 대신한다고 보지 않는다.

## 확인한 핵심 동작

1. Space 그리기가 꺼져 있으면 안전한 땅에서만 걷는다. 선을 긋다 놓으면 더 나아가지 않고, 자기 선을 거꾸로 되짚어 취소할 수 있다.
2. 실제 격자 위치와 화면 위치를 분리해 보간한다. 같은 경로의 50Hz/100Hz 실행 결과가 한 칸 이상 어긋나지 않고 멈춘 뒤 화면 위치가 실제 위치에 도착한다.
3. 기본 속도는 10칸/초, 별과 구두의 총 상한은 14칸/초다. 등껍질은 감속하며 세 번 보호한다.
4. 작은 영역을 닫으면 그 안의 일반 적과 보스가 사라지고 내 땅이 된다. 큰 영역의 적은 남는다. 피해는 현재 선만 지우고 확보한 땅을 보존한다.
5. 목표는 이야기 순서별 42%, 55%, 60%, 64%, 67%, 70%, 73%, 76%로 고정된다. 먼저 깬 이야기 수나 옛 저장의 난이도 값으로 뒤바뀌지 않는다.
6. 첫 두 동화에는 공격이 없다. 세 번째부터 공격 전 2초 예고와 공격 후 회복 단계를 거친다. 빛줄기는 확보한 땅에 막히며, 보스를 포획하면 진행 중인 예고·빛줄기가 취소된다.
7. 받은 능력을 모두 사용할 수 있지만 공용 도움 별 3개와 재사용 대기시간을 지킨다. 시계·사과는 각 1회, 나머지는 각 2회다. 연속 정지도 이 한도를 우회하지 못한다.
8. v1 저장의 능력·횟수를 v2 공용 에너지로 변환한다. v2 저장은 버프·횟수·예고 상태를 보존하며, 이어하기는 안전한 출발점과 그리기 해제 상태로 시작한다.
9. Enter/Space로 그림 동화를 한 컷씩 넘긴다. 키 반복으로 여러 컷을 건너뛰지 않는다. 지도 방향키/Enter, M으로 지도, C로 이어하기, S로 게임 저장, Esc로 쉬기, 숫자키로 선물 사용을 확인한다.
10. Space 해제, 여러 방향키의 눌림/해제, 쉬기, 창 포커스 이탈 시 입력이 남지 않는다. 보호자 창을 띄우면 뒤의 이야기 페이지가 Enter로 넘어가지 않는다.

## 발견과 수정 확인

| 발견 | 조치 및 상태 |
|---|---|
| 0 또는 비정상 dt가 0으로 정규화되어도 첫 이동이 발생 | 블루이가 dt≤0 조기 반환으로 수정. 자체 회귀 검증 추가 |
| 손상 저장의 돌진 상태·고속 속도 조합이 영구 돌진을 만들 가능성 | 블루이가 실제 돌진 단계·패턴·기본 속도 조합을 검증하고 불일치 고속 저장을 원자적으로 거부하도록 수정 |
| 자동 저장 읽기가 막힌 환경에서 안내 문구가 비어 있음 | 메인이 읽기 실패 시 안내 문구를 설정하도록 수정. 해당 앱 회귀 검증 통과 |
| 길이 0인 빛줄기가 화면에서는 기본 길이 90으로 표시됨 | 메인이 유한한 길이 0을 그대로 사용하도록 수정. 해당 앱 회귀 검증 통과 |

짧은 키 입력이 애니메이션 프레임 사이에 끝나도 한 칸 움직이도록 즉시 입력을 연결했다. 반복 keydown과 다음 프레임이 한 칸을 중복 추가하지 않는지, 방향을 바꿨을 때 보간하는지에 대한 개발자 회귀 검증도 최종 실행에 포함했다.

## 메인 실제 브라우저 검수 보고

메인은 실제 브라우저에서 Enter로 홈→지도, 방향키로 3번째 동화 선택, Enter/Space로 이야기→게임 이동, 방향키만으로 외부 진입이 막히는 동작, 숫자 1로 등껍질 사용과 도움 별 감소를 확인했다고 보고했다. 이 결과는 힐러의 DOM 모형 검증과 별도다. 최종 화면·보스 패턴의 시각 표현·짧은 키 입력 등 나머지 실제 브라우저 통합 검수는 메인의 최종 보고를 따른다.

## 실제 환경과 사용성 범위

최종 이미지 파일의 시각 품질, 실제 브라우저의 화면 크기·키보드 입력·소리, 내보낸 HTML의 파일 실행은 메인 통합 검수로 구분한다. 실제 iOS/Android 기기 및 실제 7세 플레이어로 시험하지 않았다. 부모와 아이가 첫 동화를 함께 해 보고 그리기 입력과 예고를 이해하는지, 목표 비율과 속도가 편한지 관찰할 필요가 있다. 이 자동 검증을 아동 사용성이나 실기기 호환성 보장으로 표현하지 않는다.
